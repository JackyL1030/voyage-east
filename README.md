# Voyage East - Travel Website

## About This Project

This is a beginner-level website that showcases three destinations: Japan, Hong Kong, and Taiwan. The website allows users to explore a bit of what each place has to offer.

## Live Preview
https://jackyl1030.github.io/voyage-east/

## Features

### HTML Features:

- 3 web pages
- Navigation bar
- Table (destination comparison)
- 2 forms (trip planner and feedback form)
- Dropdown Menu
- Images and GIF

### CSS Features:

- Inline, internal styling and CSS filed used
- Hover effects and simple animations

### Tools Used

- HTML
- CSS
- Bootstrap 5
- Google Fonts
